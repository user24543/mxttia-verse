# Mxttia Verse

create a personal website: Create a futuristic digital artist portfolio website for me. My current website is mxttia.it, but I want a completely new creative direction.

The website should feel like a mix between:

- futuristic Y2K aesthetics

- cyberpunk minimalism

- digital art gallery

- experimental design studio

- sci-fi interface from the year 2050

- premium but not corporate

Do NOT make it look like a typical portfolio, agency, or LinkedIn-style website. It should feel like an artist made it.

Design philosophy:

- Minimal layout but with insane attention to details

- Lots of negative space

- Experimental animations

- Smooth transitions everywhere

- Modern Y2K nostalgia mixed with futuristic UI

- Unique, memorable, "wow" factor

Visual style:

- Dark background (black / deep blue / charcoal)

- Neon accents (electric blue, purple, cyan, magenta)

- Glassmorphism elements

- Subtle gradients

- Chrome / holographic effects

- Soft glowing elements

- Abstract 3D shapes floating in the background

- Particle effects

- Scanlines / subtle digital noise

- Futuristic typography

- Clean but unconventional layouts

Homepage:

Create an immersive landing page.

Hero section:

- Large animated title:

  "MATTIA"

  or "MATTIA — DIGITAL ARTIST"

- Add a futuristic subtitle:

  "Creating digital worlds, visuals and experiences"

- The hero should have a cinematic feeling

- Add animated 3D objects, particles, or abstract forms moving slowly behind the text

- Add mouse interaction effects (elements react to cursor movement)

- Smooth parallax effects

Navigation:

Create a minimal floating navigation:

- Work

- About

- Experiments

- Contact

The navigation should feel like a futuristic operating system interface, not a normal navbar.

Portfolio section:

Create an amazing gallery for my work:

- Large immersive project cards

- Hover animations

- Images expand smoothly

- 3D perspective effects

- Glowing borders

- Video previews if available

- Projects should feel like entering different digital worlds

Add categories:

- 3D Art

- Motion Design

- VJ / Live Visuals

- Digital Experiments

About section:

Keep it short and artistic.

Not a boring biography.

Make it feel like:

"Mattia is a digital artist exploring the intersection between technology, visual culture and futuristic experiences."

Add:

- Animated timeline

- Skills displayed as futuristic tags

- Software/tools section:

  Houdini, Maya, TouchDesigner, Cinema 4D, Photoshop, Substance, After Effects, DaVinci Resolve

Experiments section:

Create a space for random creative projects.

Make it look like a futuristic archive/database.

Contact section:

Minimal:

"Let's create something impossible."

Add futuristic social links.

Animations:

Use:

- Framer Motion

- Smooth scrolling

- Cursor effects

- Magnetic buttons

- Hover distortions

- Text animations

- Image reveal animations

- Subtle 3D movement

- Loading screen animation like a futuristic system boot sequence

Add a custom loading screen:

Example:

"INITIALIZING DIGITAL ARCHIVE..."

"LOADING VISUAL SYSTEMS..."

"READY."

Important:

The website should not feel like a startup website.

It should feel like a digital artist's personal universe.

Make it responsive for desktop and mobile.

Use modern technologies:

- React

- Tailwind CSS

- Framer Motion

- Three.js if useful

Prioritize creativity, atmosphere and originality over conventional portfolio design. this is my current website: https://www.mxttia.it , take elements from there. at the end, upload it to a github repository in my connected account.
